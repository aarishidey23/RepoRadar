## 🛰️ RepoRadar — Your Radar for the World of GitHub

**Discover developers. Explore repositories. Find your next coding obsession.**

RepoRadar is an interactive web app built to make exploring GitHub easier, smarter, and more fun. Whether you're discovering inspiring developers, exploring open-source projects, checking out programming languages, or saving repositories you love, RepoRadar brings your GitHub exploration into one place.

> 💡 Think of it as your personal radar for discovering what's happening in the world of code.

## ✨ Features

🔎 **GitHub Profile Explorer**  
Search for GitHub users and explore their developer profiles.

📂 **Repository Discovery**  
Browse repositories and discover interesting projects from the open-source community.

💻 **Programming Language Insights**  
Explore the programming languages used across projects and get a better feel for a developer's tech stack.

⭐ **Favorites & Bookmarks**  
Keep track of repositories that catch your eye, so you can revisit your favorite finds.

🎨 **Clean, Interactive Experience**  
Enjoy a modern interface designed to make developer discovery feel simple and engaging.

## 🎯 Why RepoRadar?

GitHub is full of incredible projects, but finding the right ones can take time.

RepoRadar helps bring discovery closer to you — whether you're a student looking for inspiration, a developer exploring new tools, or a curious learner ready to dive into open source.

**Less searching. More discovering. More building.**

## 💻 Run Locally

Want to explore the code or contribute? Get started with these steps.

**1. Clone the repository**

```bash
git clone https://github.com/aarishidey23/RepoRadar.git
cd RepoRadar
```

**2. Install dependencies**

```bash
npm install
```

**3. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to view the app.

**4. Build for production**

```bash
npm run build
```
